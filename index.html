    GUIA DE USO

    BBCode.Lab.

    Escolha um assunto e explore o editor no seu ritmo.

    Começar a escrever

    Na aba Visual, digite ou cole seu conteúdo. Selecione letras, palavras ou parágrafos para abrir o menu de edição. Use BBCode para escrever tags diretamente. A validação indica a linha dos erros.

    Biblioteca de salvos

    Na aba Salvos, escolha Salvar atual para guardar o BBCode. Ao copiar ou baixar o código, ele também entra automaticamente no histórico local. Use Abrir, Copiar ou Excluir em cada item. Os registros ficam armazenados apenas neste navegador; limpar os dados do navegador pode apagá-los.

    Ícones e sombras

    Em Mais → Ícone Font Awesome, insira classes como fas fa-envelope-open-text. O editor interpreta a marcação HTML <i class="fas fa-envelope-open-text"></i> e preserva o código. Na tabela, ajuste font-size, font-weight, font-family, line-height e letter-spacing pelo ícone de tipografia. O ícone de sombra aceita várias camadas com controles de posição, desfoque, expansão, cor e opacidade, além do CSS em HEX ou rgba(). A renderização no fórum depende de ele permitir HTML, CSS e Font Awesome.

    Formatar texto

    Use os botões da barra ou selecione um trecho para aumentar ou diminuir a fonte, definir um tamanho exato, trocar a família tipográfica, ajustar cores, negrito, itálico, sublinhado, riscado e alinhamento. O menu Mais reúne vídeos, efeitos e outras tags. Os tamanhos podem ser personalizados.

    Links, imagens e outros blocos

    Os ícones de link e imagem abrem campos para colar o endereço. A opção de imagem também aceita largura e altura. Spoilers, citações, códigos, listas e conteúdo oculto podem ser inseridos vazios e preenchidos depois.

    Criar e editar tabelas

    Abra Tabela, escolha linhas e colunas e insira. Clique em uma célula para selecionar a tabela e abrir seus ícones: copiar, duplicar, alterar largura, cantos, cor, bordas, imagem, linhas e colunas. A prévia dos menus só é mantida depois de Confirmar.

    Bordas para mensagens privadas

    Selecione a tabela, abra o ícone de bordas e escolha Mensagem privada. Ajuste espessura, estilo (sólida, tracejada, pontilhada ou dupla), cor e transparência. Também é possível remover todas as bordas. Alguns fóruns limitam estilos CSS nos tópicos públicos.

    Imagens dentro das tabelas

    Na tabela, abra o ícone de imagem. Para tópicos, uma imagem é adicionada dentro da célula; para mensagens privadas, você pode optar por imagem de fundo. Selecione a imagem e use as setas para mudar sua ordem na célula. Para tamanhos e recortes, utilize a ferramenta de inserção de imagens. Somente tabelas flutuantes podem ser arrastadas ou giradas livremente.

    Mover, aumentar e girar elementos

    Clique em uma imagem ou dê dois cliques em um spoiler, código, citação ou título. Use as setas para cima e para baixo para reorganizar esses elementos sem CSS adicional. Tabelas comuns também podem ser reposicionadas apenas na ordem do conteúdo e redimensionadas. Para arrastar livremente ou girar uma tabela, ative primeiro Tabela flutuante em Posição e camadas. O editor não gera estilos em [img], [spoiler] ou [code].

    Habbo Imager clássico

    Abra o botão Habbo, digite o nickname, escolha hotel, expressão, ação, item de mão, tamanho, corpo ou cabeça, direção e formato. É possível definir largura, altura e recorte. Veja a prévia, copie a URL ou insira o avatar. Prévia gerada pelo nickname.

    BBCode, validação e exportação

    Alterne entre Visual e BBCode para conferir as tags. O editor avisa quando encontra fechamentos incorretos. Use Copiar BBCode para levar o texto ao Forumeiros ou Baixar .txt para salvar no computador. Desfazer e Refazer ajudam a recuperar mudanças.

    Aparência e atalhos

    Troque entre os temas claro e escuro no botão superior. Use Ctrl+B, Ctrl+I e Ctrl+U para as formatações mais comuns. O tutorial é opcional e pode ser fechado a qualquer momento.
